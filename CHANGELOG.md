# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

## [0.1.0] - 2026-06-01

### Added

- Initial `failure-packager` and `failpack` CLI.
- Run mode for commands after `--`.
- Log ingest mode with `--log`.
- Markdown and optional JSON reports.
- Framework detection for Vitest, Jest, pytest, Playwright, Go test, Cargo test, and generic Node package scripts.
- Sanitized environment, git, and package manager context.
